# 🧮 Calculadora Web

Este es un proyecto simple de una **calculadora web** realizada con **HTML, CSS y JavaScript**, como parte de mi repaso de estos lenguajes. La calculadora permite realizar operaciones matemáticas básicas y fue creada para practicar la estructura de un sitio, estilos con CSS y la lógica con JavaScript.

## 🚀 Tecnologías utilizadas

- **HTML5** – para la estructura de la calculadora.
- **CSS3** – para los estilos visuales y diseño responsivo.
- **JavaScript** – para la lógica funcional y la interacción del usuario.

## ✨ Funcionalidades

- Realiza operaciones básicas: suma, resta, multiplicación y división.
- Botón de borrar (CE) y reinicio (C).
- Interfaz intuitiva y responsive.
- Interacción mediante botones (clic).

## 📂 Estructura del proyecto
          📁 calculadora/
          ├── index.html # Estructura del sitio
          ├── style.css # Estilos de la calculadora
          └── script.js # Lógica y eventos de la calculadora

## 🧠 Objetivos del proyecto

- Reforzar conocimientos de HTML, CSS y JavaScript puro.
- Practicar la manipulación del DOM.
- Aplicar lógica de programación básica en un proyecto real.
- Mejorar la organización del código y estructura de carpetas.
